# skills

  A collection of reusable agent skills for AI-assisted work.

  ## Skill Index

  | Skill | Description |
  |-------|-------------|
  | [pharma-ba-advisor](./pharma-ba-advisor/) | BioPharma BA/PM advisory mode — Grill → Analyze → PRD → Slice（交付切片） |

  ## Installation

  Each skill is a self-contained folder. Copy the folder you want into your agent's skills directory:

  - **Replit Agent** → `.agents/skills/<skill-name>/`
  - **Claude Code** → `.claude/skills/<skill-name>/`

  Then restart or reload the agent so it picks up the new skill.
